# tests/: automated tests (Jest)

| Path                                    | What's inside                                                                                                                                                                                                                                             |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `setup/globalSetup.js`                  | Starts one in-memory MongoDB **replica set** for the whole run                                                                                                                                                                                            |
| `setup/globalTeardown.js`               | Stops it                                                                                                                                                                                                                                                  |
| `setup/env.js`                          | Fake env vars before every file; one database per Jest worker; rate limits off                                                                                                                                                                            |
| `helpers/db.js`                         | `connectTestDB`, `clearTestDB` (also empties the email outbox), `closeTestDB`                                                                                                                                                                             |
| `helpers/factories.js`                  | `api()`, `createUser()`, `createAdmin()`, `loggedIn()`, `bearer()`, `uniqueEmail()`, `tokenFromLastEmail()`, `PASSWORD`, `validAddress()`, `createAddress(user)`, `createCategory(overrides)`, `createProduct()`, `validProduct(category)`, `fakeImage()` |
| `unit/user.model.test.js`               | Defaults, validation, `comparePassword`, `isTokenOutdated`, hashed tokens, expiry, `toJSON`                                                                                                                                                               |
| `unit/middleware.test.js`               | `authorize`, `requireVerifiedEmail`, `validate`, `notFound`, `errorHandler` mappings                                                                                                                                                                      |
| `unit/utils.test.js`                    | `generateToken`, `ApiError`, `sendSuccess`, `asyncHandler`, templates + escaping, outbox                                                                                                                                                                  |
| `integration/auth.test.js`              | Every `/api/auth` route: happy paths, validation table, enumeration, injection, forged/expired tokens, email flows                                                                                                                                        |
| `integration/google.test.js`            | Google sign-in with a stubbed verifier: create, link, refuse admins/disabled, invalid tokens                                                                                                                                                              |
| `integration/users.test.js`             | Change password: fresh token, old token revoked (`tokenVersion`), errors                                                                                                                                                                                  |
| `integration/profile.test.js`           | Profile get/update: partial update, clear phone, mass assignment ignored, 400s, admins too                                                                                                                                                                |
| `integration/addresses.test.js`         | Every `/api/addresses` route: 401/403 per route, IDOR → 404 on every verb, max 5, exactly-one-default rules, transaction rollback, unique partial index                                                                                                   |
| `unit/address.model.test.js`            | Address schema rules and defaults, the partial index definition, `User.phone`, new constants and regexes                                                                                                                                                  |
| `unit/validateObjectId.test.js`         | `validateObjectId`: valid ids pass; short, non-hex, 12-char and missing ids → 400                                                                                                                                                                         |
| `integration/categories.test.js`        | Every `/api/categories` route: public vs inactive, 401/403 on admin routes, slug generation/numbering/rename, 409 names (any case, race), two-level hierarchy, delete rules                                                                               |
| `unit/category.model.test.js`           | Category schema rules, indexes, `children` virtual, slug hook guard, image sub-schema (Cloudinary URL)                                                                                                                                                    |
| `unit/slugify.test.js`                  | `slugify` cases (accents, symbols, Urdu) and `uniqueSlug` numbering with a fake model                                                                                                                                                                     |
| `integration/products.test.js`          | Every `/api/products` route: active-only reads, filters, keyword (text index), sorts, pagination + tie-breaker, by slug, create/update/delete/remove image/stock with 400/401/403/404/409, mass assignment, Cloudinary clean-up (stubbed)                 |
| `integration/products.admin.test.js`    | Admin read handlers for branch 10 (`adminList`, `lowStock`, `adminGet`) on a tiny test app                                                                                                                                                                |
| `integration/product.model.db.test.js`  | Slug hook, unique SKU/slug indexes, `reserveStock` race (no overselling), `releaseStock`, transactions, `adjustStock` + 50-entry history                                                                                                                  |
| `integration/uploads.test.js`           | `/api/uploads/image` with a fake Cloudinary: types, 2 MB limit, field name, 2 files, folders, 500/502, 401/403, delete rules                                                                                                                              |
| `integration/category-products.test.js` | Category delete refused while products use it, category image clean-up, `listAllWithCounts`                                                                                                                                                               |
| `integration/avatar.test.js`            | Google photo becomes the new user's `avatar`                                                                                                                                                                                                              |
| `unit/product.model.test.js`            | Product schema rules, virtuals, index definitions, branch 04 constants                                                                                                                                                                                    |
| `unit/product.query.test.js`            | The whitelist filter, sorts, regex escaping                                                                                                                                                                                                               |
| `unit/pagination.test.js`               | `getPagination` / `buildMeta` with good and nonsense values                                                                                                                                                                                               |
| `unit/cloudinary.test.js`               | The real `cloudinaryClient` against a fake SDK; `uploadBuffer`, `deleteImage`                                                                                                                                                                             |
| `integration/app.test.js`               | Health, 404 shape, OpenAPI coverage of routes, Swagger UI, helmet headers, CORS                                                                                                                                                                           |
| `integration/rateLimit.test.js`         | Limits switched ON: 6th admin-login attempt → 429                                                                                                                                                                                                         |
| `integration/db.test.js`                | `connectDB` connects and caches                                                                                                                                                                                                                           |

Run: `npm test` · How it all works: [docs/testing/README.md](../../docs/testing/README.md)
