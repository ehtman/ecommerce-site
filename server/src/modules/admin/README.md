# src/modules/admin/: the admin control room

Mounted at **`/api/admin`**. One `router.use(protect, authorize('admin'))` guards every route: no token → 401, customer → 403. No model of its own: it **reads and summarises** orders, users, products and categories.

| File                  | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `admin.validation.js` | `statsRules` (`range`, `tz`), `salesReportRules` (`from`/`to` as real `YYYY-MM-DD` days, `groupBy`, `tz`), `ordersExportRules` (+ `status`), `lowStockRules` (`threshold` 0–1000), `listCustomersRules` (`search` ≤ 100 text, `status`, `page`, `limit` ≤ 100), `statusRules` (`isActive` must be a real boolean).                                                                                                                                                                                         |
| `admin.service.js`    | `getDashboardStats` (10 parallel queries), `resolvePeriod` (time-zone-aware period + 400 rules), `getSalesReport` (`$match` + `$facet`: rows / byCategory / topProducts), `getSalesReportCsv`, `prepareOrdersExport` (cursor + async generator), `getInventoryOverview` (`$facet`), `getLowStock`, `listCustomers` (search, filter, pagination, order counts without N+1), `getCustomer` (customers only), `setCustomerStatus` (not yourself, not an admin).                                               |
| `admin.controller.js` | Thin handlers. Sets CSV download headers; streams the orders CSV with backpressure and aborts the connection on a mid-stream error.                                                                                                                                                                                                                                                                                                                                                                        |
| `admin.routes.js`     | `GET /dashboard/stats`, `GET /reports/sales`, `GET /reports/sales/export`, `GET /reports/orders/export`, `GET /inventory`, `GET /products/low-stock`, `GET /users`, `GET /users/:id`, `PATCH /users/:id/status`. Plus thin re-exports of other modules' admin handlers (the reference client's URLs): `GET /categories`, `GET /products`, `GET /products/:id`, `GET /orders`, `PATCH /orders/:id/status`, `GET /reviews`, `PATCH /reviews/:id/visibility`, `GET/POST /coupons`, `PUT/DELETE /coupons/:id`. |
| `admin.docs.js`       | OpenAPI for `/admin/*` (tag **Admin**), including `text/csv` responses; the coupon/review aliases reuse those modules' docs (`/admin/orders` is documented by `order.docs.js`).                                                                                                                                                                                                                                                                                                                            |
