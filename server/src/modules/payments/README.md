# src/modules/payments/: card payments with Stripe

Mounted at **`/api/payments`**. The webhook route is registered in `app.js` itself (raw body, before `express.json()`). No model of its own: payments are stored on the `Order` (branch 07).

| File                    | What it does                                                                                                                                                                                                                                                                                       |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `stripe.gateway.js`     | The **only** file that imports `stripe`. `stripeGateway.isConfigured()`, `getClient()` (created lazily), `createCheckoutSession(params)`, `constructEvent(raw, signature, secret)` (static `Stripe.webhooks`, no network). Tests replace `createCheckoutSession` with a fake.                      |
| `payment.service.js`    | `createCheckoutSession(user, orderId)` (ownership, card/paid/pending/30-min checks, amount from the DB, 502 if Stripe fails), `handleWebhook(rawBody, signature)` (signature → event type → `markOrderPaid`, **idempotent** with an atomic claim), `expireUnpaidOrders({ now, cancel })`, helpers. |
| `cron.middleware.js`    | `requireCronSecret`: `x-cron-secret` or `Authorization: Bearer` (Vercel Cron); 401 missing, 403 wrong. `safeEqual` = `crypto.timingSafeEqual` with a length check.                                                                                                                                 |
| `payment.validation.js` | `checkoutSessionRules`: `orderId` must be a MongoDB id. The amount is never accepted from the client.                                                                                                                                                                                              |
| `payment.controller.js` | Thin handlers: `createCheckoutSession`, `stripeWebhook` (used by `app.js`), `expireUnpaid`.                                                                                                                                                                                                        |
| `payment.routes.js`     | `POST /checkout-session` (`protect`, `authorize('customer')`, `requireVerifiedEmail`, `validate`), `GET` + `POST /expire-unpaid` (`requireCronSecret`).                                                                                                                                            |
| `payment.docs.js`       | OpenAPI for `/payments/*` (tag **Payments**) and the `cronSecret` security scheme.                                                                                                                                                                                                                 |
