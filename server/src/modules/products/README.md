# src/modules/products/: the product catalogue

Mounted at **`/api/products`**. Reads are **public** and show only **active** products. Writes need `protect` + `authorize('admin')`.

| File                    | What it does                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `product.model.js`      | The `Product` schema (name, slug, description, brand, unique SKU, whole-rupee price, compareAtPrice > price, category, 1–5 images, stock, sold, specifications, rating numbers, isFeatured, isActive, hidden `stockHistory`, createdBy). Virtuals `inStock`, `discountPercent`. Slug hook. One compound index per list + the weighted **text index**. Atomic statics `reserveStock`, `releaseStock`, `adjustStock`. |
| `product.query.js`      | `buildProductFilter` (a **whitelist**: always `isActive: true`), `getSort` + `SORTS` (each ends with `_id`), `escapeRegex`. Pure functions.                                                                                                                                                                                                                                                                         |
| `product.validation.js` | `productRules` (create and update: the whole product) and `stockRules` (`mode`, `value`, `reason`).                                                                                                                                                                                                                                                                                                                 |
| `product.service.js`    | Public: `listProducts` (pagination + filters + search + sort), `getProductBySlug`, `listBrands`. Admin: `createProduct`, `updateProduct` (deletes removed images), `deleteProduct`, `removeImage`, `updateStock`, and for branch 10 `adminListProducts`, `lowStock`, `adminGetProduct`.                                                                                                                             |
| `product.controller.js` | Thin handlers; lists send `meta`. `adminList`, `lowStock`, `adminGet` are mounted by the admin module (branch 10).                                                                                                                                                                                                                                                                                                  |
| `product.routes.js`     | `GET /`, `GET /brands`, `GET /:slug` (public); `POST /`, `PUT /:id`, `DELETE /:id`, `DELETE /:id/images/:imageId`, `PATCH /:id/stock` (admin). `// Branch 09:` nested review routes go here.                                                                                                                                                                                                                        |
| `product.docs.js`       | OpenAPI for `/products/*` (tag **Products**).                                                                                                                                                                                                                                                                                                                                                                       |
