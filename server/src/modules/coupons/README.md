# src/modules/coupons/: discount codes

Mounted at **`/api/coupons`**. `POST /validate` needs `protect` + `authorize('customer')`; every other route needs `protect` + `authorize('admin')`.

| File                   | What it does                                                                                                                                                                                                                                                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `coupon.model.js`      | The `Coupon` schema (code UPPERCASE + unique, type, value, maxDiscount, minOrderAmount, startsAt, expiresAt, usageLimit, usedCount, isActive, createdBy). `state` virtual. Methods `checkUsable(subtotal, now)` and `calculateDiscount(subtotal)` (integer math). Statics `consume` / `release`: **atomic** usage counter. |
| `coupon.validation.js` | `validateCouponRules` (customer: `code`) and `couponRules` (admin form: code pattern + uppercase, type, value range per type, optional integers, ISO dates, expiry after start).                                                                                                                                           |
| `coupon.service.js`    | `previewCoupon` (server-side cart subtotal → checks → `calcTotals`), `listCoupons`, `getCoupon`, `createCoupon` / `updateCoupon` (409 on a taken code, mass assignment protection), `deleteCoupon` (used → deactivated).                                                                                                   |
| `coupon.controller.js` | Thin handlers: `validateCoupon`, `list`, `getOne`, `create` (201), `update`, `remove`.                                                                                                                                                                                                                                     |
| `coupon.routes.js`     | `POST /validate`, `GET /`, `GET /:id`, `POST /`, `PUT /:id`, `DELETE /:id`.                                                                                                                                                                                                                                                |
| `coupon.docs.js`       | OpenAPI for `/coupons/*` (tag **Coupons**) and the `Coupon` schema.                                                                                                                                                                                                                                                        |
