# src/modules/reviews/: product reviews and ratings

Mounted at **`/api/reviews`** (one existing review). List, eligibility and create are **nested** under the product: `/api/products/:id/reviews` (wired in `../products/product.routes.js`).

| File                   | What it does                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `review.model.js`      | The `Review` schema (`user`, `product`, `order` proof, `rating` 1–5, `title`, `comment`, `isVisible`). **Compound unique** index `one_review_per_product` `{product, user}`. Static `calcProductRating` (aggregation `$match` → `$group`) writes `ratingAverage`/`ratingCount` onto the Product. Post hooks on `save`, `findOneAndUpdate` and `findOneAndDelete` keep that copy in sync. |
| `review.validation.js` | `reviewRules` (rating, title, comment), `visibilityRules` (`isVisible` boolean), `adminListRules` (optional `rating`, `visibility`, `product` filters).                                                                                                                                                                                                                                  |
| `review.service.js`    | `listForProduct` (visible, newest first, paginated), `eligibility`, `createReview` (delivered order required → 403, duplicate → 409, race → 409), `updateReview` (author only), `deleteReview` (author or admin), `adminList`, `setVisibility`.                                                                                                                                          |
| `review.controller.js` | Thin handlers shared by both route files.                                                                                                                                                                                                                                                                                                                                                |
| `review.routes.js`     | `GET /admin` and `PATCH /:id/visibility` (admin), `PUT /:id` (customer author), `DELETE /:id` (author or admin).                                                                                                                                                                                                                                                                         |
| `review.docs.js`       | OpenAPI for the nested and the `/reviews` paths (tag **Reviews**).                                                                                                                                                                                                                                                                                                                       |
