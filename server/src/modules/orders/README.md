# src/modules/orders/: checkout and order history

Mounted at **`/api/orders`** (customers; `GET /:id` also admins) and **`/api/admin/orders`** (admins only; since branch 10 these two routes are mounted by `admin/admin.routes.js` with this module's controller).

| File                  | What it does                                                                                                                                                                                                                                                                                                                                                   |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `order.model.js`      | The `Order` schema: item, address and coupon **snapshots**, money breakdown (whole rupees, total must add up), `orderNumber` (`ORD-yyyymmdd-NNNNN`, unique), `status` + `statusHistory`. State machine methods: `canTransitionTo`, `isCancellableByCustomer`, `changeStatus` (the only code that changes `status`).                                            |
| `order.validation.js` | `placeOrderRules` (`addressId`, `paymentMethod`, `couponCode`, `note`), `cancelRules` (`reason`), `statusRules` (admin: `status`, `note`, `trackingNumber`), `listRules` (query filters).                                                                                                                                                                      |
| `order.service.js`    | `placeOrder`: ONE **transaction** that reserves stock atomically (`stock >= qty`), re-checks and consumes the coupon, creates the order, empties the cart. `cancelWithRestore` (transaction: status + stock + coupon back), `cancelMyOrder` (BR-06), `getMyOrders`, `getOrderById` (owner or admin), `adminListOrders`, `adminUpdateStatus`, `sendOrderEmail`. |
| `order.controller.js` | Thin handlers: `placeOrder` (201), `getMyOrders`, `getOrderById`, `cancelOrder`, `adminList`, `adminUpdateStatus`.                                                                                                                                                                                                                                             |
| `order.routes.js`     | Customer router: `POST /` (verified email), `GET /my`, `GET /:id`, `PATCH /:id/cancel`. (Admin `GET /api/admin/orders` and `PATCH /api/admin/orders/:id/status` are in `admin.routes.js`.)                                                                                                                                                                     |
| `order.docs.js`       | OpenAPI for `/orders/*` and `/admin/orders/*` (tags **Orders**, **Admin – Orders**) plus the `Order`, `OrderItem`, `ShippingAddress`, `OrderSummary`, `PageMeta` schemas.                                                                                                                                                                                      |
