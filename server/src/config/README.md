# src/config/: settings and connections

| File            | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Used by                            |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| `env.js`        | The **only** reader of `process.env`. Loads `.env`, exits if `MONGO_URI`/`JWT_SECRET` are missing (fail fast), applies defaults, converts types, adds `isProduction`, `isTest`, `CLIENT_URLS`, `FRONTEND_URL`. Branch 07: `PAYMENT_CARD_ENABLED` (default false).                                                                                                                                                                                                                                                                                                                                                                                                                                                               | almost every file                  |
| `constants.js`  | Frozen business constants: `ROLES`, `AUTH_PROVIDERS`, `TOKEN_TTL` (24 h verify / 30 min reset), `REGEX` (`EMAIL`, `PK_PHONE`, `POSTAL_CODE`, `SLUG`, `CLOUDINARY_URL`, `SKU`, `COUPON_CODE`), `PROVINCES`, `ADDRESS_LABELS`, `LIMITS` (`MAX_ADDRESSES`; products: `MAX_PRODUCT_IMAGES`, `MAX_SPECIFICATIONS`, `STOCK_HISTORY_KEEP`, `LOW_STOCK_THRESHOLD`, `MAX_IMAGE_BYTES`; cart: `MAX_CART_QTY`, `MAX_WISHLIST`; coupons: `COUPON_MAX_PERCENT`, `COUPON_MAX_FIXED`), `COUPON_TYPES`, `PRICING` (`SHIPPING_FEE`, `FREE_SHIPPING_MIN`, `TAX_RATE`), `IMAGE_MIME_TYPES`. Branch 07: `ORDER_STATUS`, `ORDER_TRANSITIONS` (the state machine arrows, BR-08), `CUSTOMER_CANCELLABLE` (BR-06), `PAYMENT_METHODS`, `PAYMENT_STATUS`. | models, middleware                 |
| `cloudinary.js` | The Cloudinary SDK set up from `CLOUDINARY_*`, behind a small stubbable `cloudinaryClient` (`isConfigured`, `upload`, `destroy`). `uploadBuffer(buffer, folder)` → `{ url, publicId }` (500 not configured / 502 failed); `deleteImage(publicId)` never throws and only deletes `shopease/…` files. `IMAGE_FOLDERS`.                                                                                                                                                                                                                                                                                                                                                                                                            | uploads, products, categories      |
| `db.js`         | `connectDB()`: one cached Mongoose connection (works for local and serverless), `strictQuery`, pool size 5, `autoIndex` off in production.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | `server.js`, `api/index.js`, tests |

Concepts: [09 – Config and environments](../../../docs/concepts/09-config-and-environments.md), [10 – Databases and indexes](../../../docs/concepts/10-databases-and-indexes.md).
