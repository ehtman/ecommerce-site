# src/config/: settings and connections

| File            | What it does                                                                                                                                                                                                                                                                                                                                                                        | Used by                            |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| `env.js`        | The **only** reader of `process.env`. Loads `.env`, exits if `MONGO_URI`/`JWT_SECRET` are missing (fail fast), applies defaults, converts types, adds `isProduction`, `isTest`, `CLIENT_URLS`, `FRONTEND_URL`.                                                                                                                                                                      | almost every file                  |
| `constants.js`  | Frozen business constants: `ROLES`, `AUTH_PROVIDERS`, `TOKEN_TTL` (24 h verify / 30 min reset), `REGEX` (`EMAIL`, `PK_PHONE`, `POSTAL_CODE`, `SLUG`, `CLOUDINARY_URL`, `SKU`), `PROVINCES`, `ADDRESS_LABELS`, `LIMITS` (`MAX_ADDRESSES`; products: `MAX_PRODUCT_IMAGES`, `MAX_SPECIFICATIONS`, `STOCK_HISTORY_KEEP`, `LOW_STOCK_THRESHOLD`, `MAX_IMAGE_BYTES`), `IMAGE_MIME_TYPES`. | models, middleware                 |
| `cloudinary.js` | The Cloudinary SDK set up from `CLOUDINARY_*`, behind a small stubbable `cloudinaryClient` (`isConfigured`, `upload`, `destroy`). `uploadBuffer(buffer, folder)` → `{ url, publicId }` (500 not configured / 502 failed); `deleteImage(publicId)` never throws and only deletes `shopease/…` files. `IMAGE_FOLDERS`.                                                                | uploads, products, categories      |
| `db.js`         | `connectDB()`: one cached Mongoose connection (works for local and serverless), `strictQuery`, pool size 5, `autoIndex` off in production.                                                                                                                                                                                                                                          | `server.js`, `api/index.js`, tests |

Concepts: [09 – Config and environments](../../../docs/concepts/09-config-and-environments.md), [10 – Databases and indexes](../../../docs/concepts/10-databases-and-indexes.md).
