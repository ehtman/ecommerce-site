# src/utils/: small shared helpers

| File               | Export                                                                                       | What it does                                                                                                                                                                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ApiError.js`      | `ApiError` (class)                                                                           | `new ApiError(status, message, errors?)`: an Error with an HTTP status; thrown anywhere, answered by the error handler.                                                                                                                                                               |
| `ApiResponse.js`   | `sendSuccess(res, status, message, data?, meta?)`                                            | Sends `{ success: true, message, data, meta? }`.                                                                                                                                                                                                                                      |
| `asyncHandler.js`  | `asyncHandler(fn)`                                                                           | Wraps async controllers so thrown errors reach `next(err)` (Express 4 doesn't do it).                                                                                                                                                                                                 |
| `generateToken.js` | `generateToken(user)`                                                                        | Signs a JWT `{ id, role, v }` with `JWT_SECRET`, expiring after `JWT_EXPIRES_IN`.                                                                                                                                                                                                     |
| `pagination.js`    | `getPagination(query, default, max)`, `buildMeta(page, limit, total)`                        | Safe `page`/`limit`/`skip` from the query string (capped) and the `meta` object for list responses.                                                                                                                                                                                   |
| `pricing.js`       | `calcShipping(amount)`, `calcTotals(itemsPrice, discountPrice?)`                             | Pure money helpers: Rs 250 shipping, free from Rs 5,000 (`PRICING`), no tax, whole rupees. `calcTotals` builds `{ itemsPrice, discountPrice, shippingPrice, taxPrice, totalPrice }`; free shipping is judged **after** the discount. Used by the cart, the coupon preview and orders. |
| `dates.js`         | `isValidTimeZone`, `tzOffsetMs`, `startOfDayInZone`, `endOfDayInZone`, `dayInZone`, `DAY_MS` | Time-zone-aware calendar days for reports, using the built-in `Intl` API (branch 10).                                                                                                                                                                                                 |
| `csv.js`           | `csvCell`, `csvRow`, `CSV_BOM`                                                               | Safe CSV: RFC 4180 quoting, CRLF, UTF-8 BOM, formula-injection guard (branch 10).                                                                                                                                                                                                     |

Tests: `tests/unit/utils.test.js`, `tests/unit/pagination.test.js`, `tests/unit/pricing.test.js`, `tests/unit/coupon.model.test.js` (`calcTotals`), `tests/unit/reporting.test.js` (dates, csv)
